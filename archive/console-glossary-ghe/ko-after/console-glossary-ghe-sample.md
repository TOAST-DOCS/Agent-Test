## 일정 생성 예시

이 문서는 사내 다국어 DB 의 콘솔 문자열을 번역이 따르는지 확인하는 e2e 픽스처입니다.

### 일정 만들기

1. **일정 생성**을 클릭합니다.
2. **실행 유형**에서 **일회성** 또는 **반복**을 선택합니다.
3. **결과 검증 조건**을 추가하고 **조건 결합 방식**을 선택합니다.
    * **모든 조건 일치**: 추가한 조건을 모두 만족해야 성공으로 판단합니다.
    * **일부 조건 일치**: 조건 중 하나라도 만족하면 성공으로 판단합니다.
4. **결과 알림**에서 **발송 기준**을 정하고 **실패 사유 포함** 여부를 선택합니다.
5. **다음**을 클릭합니다.

!!! tip "알아두기"
    다음 중 하나에 해당하면 일정이 실행되지 않습니다.

    * 대상 서비스가 삭제된 경우
    * 일정이 비활성화된 경우

### 재시도 설정

| 항목 | 설명 |
| --- | --- |
| 재시도 정책 | 실패한 실행을 다시 시도하는 방식입니다. |
| 재시도 간격 | 다시 시도하기 전에 기다리는 시간입니다. |
