## フロー { #flow }

<a id="flow-overview"></a>
### 概要 { #flow-overview }

フローを作成して実行します。

<a id="execution-history"></a>
### 実行履歴 { #execution-history }

フローの実行履歴を実行単位で表示します。

<a id="execution-history-execution-list"></a>
#### 実行リスト

* 実行ID、状態、開始時刻、終了時刻、所要時間を表示します。
* 失敗理由
    * 失敗した実行の失敗理由を表示します。失敗理由は次の3つのいずれかです。
        * フローのエンジンタイプを実行できません。
        * 実行可能なフローリソースを超過しました。
        * フローを実行できませんでした。
* フィルタ
    * 状態フィルタで全体、成功、失敗のいずれかを選択してリストを絞り込めます。
    * 期間フィルタで直近1日、直近7日、直近30日、全体のいずれかを選択できます。

<a id="execution-history-execution-details"></a>
#### 実行詳細

* 概要
    * 実行ID、実行状態、開始時刻、終了時刻を表示します。
* ログ
    * **ログクエリのコピー**:この実行のログのみを照会するクエリをコピーします。

<a id="execution-history-execution-metrics"></a>
#### 実行メトリクス

選択した実行のグラフとメトリクスチャートをモーダルウィンドウに表示します。

* 期間
    * **全実行**を選択すると、実行開始から終了までのメトリクスを照会します。
    * メトリクスは直近16日まで保管されます。

<a id="schedule-list"></a>
### スケジュールリスト { #schedule-list }

登録されたスケジュールを表示します。
