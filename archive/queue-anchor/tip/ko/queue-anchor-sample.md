## 플로우 { #flow }

<a id="flow-overview"></a>
### 개요 { #flow-overview }

플로우를 생성하고 실행합니다.

<a id="execution-history"></a>
### 실행 이력 { #execution-history }

플로우의 실행 이력을 실행 단위로 표시합니다.

<a id="execution-history-execution-list"></a>
#### 실행 목록

* 실행 아이디, 상태, 시작 시각, 종료 시각, 소요 시간을 표시합니다.
* 실패 사유
    * 실패한 실행의 실패 사유를 표시합니다. 실패 사유는 다음 4가지 중 하나입니다.
        * 플로우의 엔진 유형을 실행할 수 없습니다.
        * 실행 가능한 플로우 리소스를 초과했습니다.
        * 플로우를 실행하지 못했습니다.
        * 인증에 실패해 플로우를 중지했습니다. 키를 확인한 후 다시 실행해 주세요.
* 필터
    * 상태 필터로 전체, 성공, 실패 중 하나를 선택해 목록을 좁힐 수 있습니다.
    * 기간 필터로 최근 1일, 최근 7일, 최근 30일, 전체 중 하나를 선택할 수 있습니다.

<a id="execution-history-execution-details"></a>
#### 실행 상세

* 개요
    * 실행 아이디, 실행 상태, 시작 시각, 종료 시각을 표시합니다.
    * 인증 실패로 시스템이 중지한 실행은 중지 요청자를 **시스템**으로 표시합니다.
* 로그
    * **로그 쿼리 복사**: 이 실행의 로그만 조회하는 쿼리를 복사합니다.

<a id="execution-history-execution-metrics"></a>
#### 실행 메트릭

선택한 실행의 그래프와 메트릭 차트를 모달 창에 표시합니다.

* 기간
    * **전체 실행**을 선택하면 실행 시작부터 종료까지의 메트릭을 조회합니다.
    * 메트릭은 최근 16일까지 보관합니다.
