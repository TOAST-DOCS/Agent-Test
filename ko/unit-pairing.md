# unit-pairing e2e 픽스처

이 문서는 자동 생성된 e2e 픽스처입니다 (20260927-030730).

<a id="upair-box"></a>
## 상자 앞에 끼우기 { #upair-box }

이 섹션은 상자 앞에 새 문단이 들어가는 모양을 재현합니다.

예시로 보기 행에는 입력한 설정으로 예시 지표가 몇 개의 시리즈로 나뉘는지 표시됩니다.

- **예시 보기**를 클릭하면 요청 본문 예시가 펼쳐집니다.
- 입력을 바꾸면 즉시 다시 계산됩니다.

!!! tip "알아두기"
    데이터를 보내는 방법은 생성 완료 창, 자세히 보기의 **수집 방법** 탭을 참고합니다.
    이 줄은 ko 가 건드리지 않는 상자의 둘째 줄입니다.

<a id="upair-split"></a>
## 문단 가르기 { #upair-split }

설정할 수 있는 값은 세 가지입니다.
값의 형식은 BCP 47 언어 태그 표준을 따릅니다.

- 기본 언어: 소문자 2자리 코드
- 지역 구분: 언어-국가 조합

값은 반드시 아래 표에 있는 것만 사용할 수 있습니다.

| 값 | 설명 |
|---|---|
| ko | 한국어 |
| en | 영어 |
| ja | 일본어 |
