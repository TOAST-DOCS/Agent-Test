<a id="compute-instance-version-guide"></a>
## Compute > Instance > 버전 가이드 { #compute-instance-version-guide }

인스턴스 서비스가 지원하는 클러스터 이미지 버전과 릴리스 히스토리를 정리한 문서입니다. 각 버전에서 도입된 주요 변경 사항과 마이너 버전 업그레이드 정책, 지원 종료 일정을 함께 소개합니다. 신규 클러스터를 생성할 때는 최신 마이너 버전이 기본으로 선택되며, 이미 운영 중인 클러스터는 콘솔 또는 API 를 통해 마이너 버전 업그레이드를 신청할 수 있습니다. 마이너 버전 업그레이드는 노드 풀 단위로 무중단 롤링 방식으로 진행되며, 데이터 플레인에는 영향이 없습니다. 다만 컨트롤 플레인의 짧은 지연이 발생할 수 있으므로 트래픽이 낮은 시간대에 예약 실행하는 것을 권장합니다. 업그레이드가 진행되는 동안에는 신규 워크로드 배포와 노드 풀 확장 요청이 큐에 대기되며, 업그레이드 완료 후 순차적으로 처리됩니다. 업그레이드가 시작되기 전 콘솔의 상세 페이지에서 예상 소요 시간과 노드 별 진행 상태를 확인할 수 있으며, 필요한 경우 노드 풀 단위로 업그레이드를 일시 중지하거나 롤백할 수 있습니다. 롤백은 마지막으로 성공한 마이너 버전으로만 가능하며, 롤백 이후에도 컨트롤 플레인은 최신 마이너 버전을 유지합니다. 롤백 이후 다시 업그레이드를 시도하려면 실패 원인을 해소한 뒤 콘솔에서 재시도 버튼을 누르면 됩니다.

<a id="upgrade-policy"></a>
### 업그레이드 정책 { #upgrade-policy }

각 마이너 버전의 표준 지원 기간은 릴리스 후 12 개월입니다. 지원 종료 60 일 전부터 콘솔 배너와 알림 채널을 통해 사전 안내가 발송되며, 지원 종료일이 지난 클러스터는 자동으로 최신 마이너 버전으로 승격됩니다. 자동 승격이 예정된 클러스터는 지원 종료 30 일 전부터 콘솔 상세 페이지의 상단에 카운트다운 배너가 노출되고, 원하는 시점에 수동으로 업그레이드를 앞당길 수 있습니다.
