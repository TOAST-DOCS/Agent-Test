## 단변량 시계열 이상탐지 개요 { #term-pin-overview }

이 문서는 단변량 시계열 이상탐지 기능을 설명합니다.

### 1. 단변량 시계열 이상탐지 설정 1 { #term-pin-1 }

단변량 시계열 이상탐지 앱을 생성하려면 먼저 데이터 소스를 준비합니다. 단변량 시계열 이상탐지 은 지표의 과거 패턴을 학습해 이상 구간을 찾습니다.

1. 콘솔에서 **단변량 시계열 이상탐지** 탭으로 이동합니다. 이 탭에서 단변량 시계열 이상탐지 앱 목록을 확인할 수 있습니다.
2. 학습 주기와 추론 주기를 지정합니다. 주기가 짧을수록 단변량 시계열 이상탐지 의 반응이 빨라지지만 비용이 늘어납니다.
3. 임계값을 설정합니다. 단변량 시계열 이상탐지 은 점수가 임계값을 넘으면 이상으로 판단합니다.
4. 생성 버튼을 클릭하면 단변량 시계열 이상탐지 앱이 만들어지고 학습이 시작됩니다.

> 참고: 단변량 시계열 이상탐지 앱은 프로젝트당 최대 10개까지 만들 수 있습니다. 자세한 내용은 단변량 시계열 이상탐지 사용 가이드를 참고합니다.
