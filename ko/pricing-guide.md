<a id="compute-instance-pricing-guide"></a>
## Compute > Instance > 요금 가이드 { #compute-instance-pricing-guide }

인스턴스 요금제와 요금제별 제공 한도를 정리한 문서입니다. 요금은 리전과 결제 방식에 따라 달라질 수 있으며, 자세한 금액은 콘솔의 요금 계산기에서 확인할 수 있습니다. (본문 수정 테스트: 이 문장은 번역 재실행 시 반영되어야 합니다.)

<a id="plan-limits"></a>
### 요금제별 한도 { #plan-limits }

| 요금제 | 최대 인스턴스 수 | 최대 블록 스토리지 | 기술 지원 |
|---|---|---|---|
| 기본 요금제 | 10대 | 1TB | 이메일 지원 |
| 표준 요금제 | 50대 | 10TB | 이메일 및 전화 지원 |
| 고급 요금제 | 200대 | 50TB | 전담 엔지니어 지원 |

<a id="billing-notes"></a>
### 과금 유의 사항 { #billing-notes }

과금은 시간 단위로 계산되며, 인스턴스를 중지해도 스토리지 요금은 계속 부과됩니다. 월 상한 요금제를 사용하는 경우 상한 초과분은 청구되지 않습니다.

<a id="snapshot-defaults"></a>
### 스냅샷 기본 정책 { #snapshot-defaults }

| 항목 | 설명 |
|---|---|
| 백업 주기 | 스냅샷을 하루 한 번 자동으로 생성합니다. |
| 보관 기간 | 생성한 스냅샷을 30일 동안 보관합니다. |
| 복원 방식 | 콘솔에서 직접 복원할 수 있습니다. |
