# 콘솔 용어집 샘플

이 문서는 콘솔 용어집 e2e 픽스처입니다.

<a id="cg-notify"></a>
## 알림 설정

1. **알림 전송**을 활성화합니다.
2. **발송 기준**에서 **실패 시**를 선택합니다.
3. 실패 원인을 메일로 받으려면 **실패 사유 포함**을 선택합니다.

<a id="cg-window"></a>
## 윈도우 설정

**지연 허용 시간**을 설정하면 윈도우가 닫힌 뒤에 도착한 메시지도 결과에 반영합니다.

<a id="cg-window-fields"></a>
## 윈도우 필드

| 항목 | 기본값 | 설명 |
| --- | --- | --- |
| 지연 허용 시간 | 0 | 윈도우가 닫힌 뒤에도 집계 상태를 유지할 시간(초) |

지연 허용 시간을 0으로 두면 늦게 도착한 메시지는 버립니다.

<a id="cg-detail"></a>
## 상세 정보 확인

**상세 정보** 탭에서 실행 결과를 확인합니다.

<a id="cg-prose"></a>
## 다음 단계

설정을 마치면 **다음**을 클릭합니다.

다음 중 하나를 선택하세요.

* 일정을 바로 실행합니다.
* 일정을 저장만 합니다.
