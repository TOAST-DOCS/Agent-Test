<a id="compute-instance-pricing-guide"></a>
## Compute > Instance > 料金ガイド { #compute-instance-pricing-guide }

インスタンスの料金プランとプラン別提供上限をまとめた文書です。料金はリージョンと決済方式によって異なる場合があり、詳細な金額はコンソールの料金計算機で確認できます。(本文修正テスト：この文は翻訳の再実行時に反映されるべきです。)

<a id="plan-limits"></a>
### プラン別上限 { #plan-limits }

| プラン | 最大インスタンス数 | 最大ブロックストレージ | 技術サポート |
|---|---|---|---|
| 基本プラン | 10台 | 1TB | メールサポート |
| 標準プラン | 50台 | 10TB | メールおよび電話サポート |
| プレミアムプラン | 200台 | 50TB | 専任エンジニアサポート |

<a id="billing-notes"></a>
### 課金に関する注意事項 { #billing-notes }

課金は時間単位で計算され、インスタンスを停止してもストレージ料金は引き続き発生します。月額上限プランを使用している場合、上限を超えた分は請求されません。
