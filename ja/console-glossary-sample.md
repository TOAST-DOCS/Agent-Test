# コンソール用語集サンプル

このドキュメントはコンソール用語集e2eフィクスチャです。

<a id="cg-notify"></a>
## 通知設定

1. **通知送信**を有効にします。
2. **送信基準**で**失敗時**を選択します。
3. 失敗原因をメールで受け取るには、**失敗の理由を含める**を選択します。

<a id="cg-window"></a>
## ウィンドウ設定

**遅延許可時間**を設定すると、ウィンドウが閉じた後に到着したメッセージも結果に反映されます。

<a id="cg-window-fields"></a>
## ウィンドウフィールド

| 項目 | デフォルト値 | 説明 |
| --- | --- | --- |
| 遅延許可時間 | 0 | ウィンドウが閉じた後も集計ステータスを保持する時間(秒) |

遅延許可時間を0に設定すると、遅れて到着したメッセージは破棄されます。

<a id="cg-detail"></a>
## 詳細内容の確認

**詳細内容**タブで実行結果を確認します。

<a id="cg-prose"></a>
## 次のステップ

設定が完了したら、**次へ**をクリックします。

次のいずれかを選択してください。

* スケジュールをすぐに実行します。
* スケジュールのみを保存します。
