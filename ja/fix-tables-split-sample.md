# 分割セル表サンプル

<a id="fix-tables-split-sample"></a>
## 分割セル表サンプル { #fix-tables-split-sample }

このドキュメントは、壊れた表の整備が**翻訳側でセルが2行に分割された表**をどのように扱うかを測るフィクスチャです。

<a id="fix-tables-split-cell"></a>
## セルが分割された表 { #fix-tables-split-cell }

コールバックメソッドを整理すると以下の表の通りです。

| コールバック名 | 意味 | 説明 |
|----------|------|------|
| onMatch | マッチリクエストを処理 | ユーザーが直接マッチリクエストを処理します。<br>
つまり、最小限のリクエストを集めて定員に合わせてマッチングします。 |
| onRefill | マッチリフィルリクエスト処理 | マッチングされたルームから誰かが出た時に新しいユーザーを補充します。 |

<a id="fix-tables-split-tail"></a>
## 最後のセクション { #fix-tables-split-tail }

| 名前 | 値 |
|------|----|
| `TIMEOUT` | -1 |
| `SUCCESS` | 0 |
