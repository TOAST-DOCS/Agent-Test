<a id="fill-stub-sample"></a>
## 空の翻訳埋めサンプル { #fill-stub-sample }

この文書は**空の翻訳埋め**(`translate/translate_fill_stubs.py`)を検証するためのテストフィクスチャです。
en/ja のコピーには pre-align が残す 2 種類の stub をわざと残してあり、埋め込み実行がその stub だけを正確に
埋め、ほかのセクションをバイト単位で保存するかを確認します。

この文書はユーザーガイドメニュー(`ko/nav.yml`)には登録しません。配布される文書ではなくパイプラインのフィクスチャです。文書整備e2eがこの文章を追加しました。

<a id="fill-stub-untouched"></a>
## すでに翻訳済みのセクション { #fill-stub-untouched }

このセクションは en/ja にすでに翻訳されています。埋め込み実行のあとも**バイト単位で同一**でなければなりません。
1 文字でも変わっていれば、埋め込みが stub の外に触れたということなので欠陥です。

<a id="fill-stub-body"></a>
## 本文だけが空のセクション { #fill-stub-body }

en/jaの同じセクションでは、見出しは翻訳済みで本文のみbody stubとして空になっています。
入力実行時は見出し行をそのままにして、この段落だけを翻訳して挿入する必要があります。

インスタンスを作成すると、コンソールのステータスが**実行中**に変わるまで数分かかる場合があります。
ステータスがなかなか変わらない場合は、イメージとインスタンスタイプの組み合わせが正しいかどうかをまず確認します。

<a id="fill-stub-table"></a>
## 表があるセクション { #fill-stub-table }

本文に表があるbody stubです。内容が入力された後も、表の列数と行数はkoと同じである必要があります。

| 項目 | 説明 | デフォルト値 |
|---|---|---|
| インスタンスタイプ | 作成するインスタンスのCPU/メモリスペック | m2.c1m2 |
| ブロックストレージ | ルートボリュームのサイズ(GB) | 20 |
| 起動スクリプト | インスタンスの初回起動時に実行するスクリプト | なし |

<a id="fill-stub-code"></a>
## コードブロックがあるセクション { #fill-stub-code }

コードブロックは翻訳の対象ではありません。以下のブロックは内容が入力された後も、そのままである必要があります。

```bash
# fill-stub-test: this line must be copied verbatim
curl -X GET "https://api.example.com/v2.0/servers" \
  -H "X-Auth-Token: ${TOKEN}"
```

ブロック外のこの文のみが翻訳の対象であり、コマンドとコメント行には手を加えません。

<a id="fill-stub-heading"></a>
## 見出しまで空のセクション { #fill-stub-heading }

en/jaの同じセクションは、見出しがまだ韓国語である見出しスタブです。
入力実行では見出しと本文を一緒に翻訳しますが、見出しのレベルと`{ #id }`はkoを正本として従う必要があります。

<a id="fill-stub-heading-child"></a>
### 子見出しも空の場合 { #fill-stub-heading-child }

heading stubが連続して現れる場合です。親セクションとは独立してそれぞれ補完される必要があり、
`###`レベルが`##`に昇格または降格されてはなりません。

<a id="section-1"></a>
## アンカーのないセクション { #section-1 }

**ネガティブコントロールです。このheadingには`<a id>`アンカーも`{ #id }`属性も付けないでください。**

フィルは共有アンカーでkoセクションを検索するため、アンカーのないstubはフィルせず、PR本文に「スキップ」と報告する必要があります。静かにフィルされたり静かに消えたりすると欠陥です。

pre-alignをこの文書に再度実行すると、このheadingにもidが付いて対照群が消えるため、その際は`archive/fill-stub/`のコピーで元に戻します。
