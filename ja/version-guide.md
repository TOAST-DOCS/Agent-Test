## Compute > Instance > バージョンガイド { #compute-instance-version-guide }

インスタンスサービスがサポートするクラスターイメージバージョンとリリース履歴についてまとめた文書です。各バージョンで導入された主な変更点、マイナーバージョンアップグレードポリシー、サポート終了スケジュールを紹介します。新規クラスターを作成する場合、最新マイナーバージョンがデフォルトで選択されます。既に運用中のクラスターについては、コンソールまたは API を通じてマイナーバージョンアップグレードを申請できます。マイナーバージョンアップグレードはノードプール単位でダウンタイムなしのローリング方式により進行され、データプレーンに影響はありません。ただし、コントロールプレーンで短時間の遅延が発生する可能性があるため、トラフィックが低い時間帯に予約実行することをお勧めします。アップグレード実行中は、新規ワークロードデプロイおよびノードプール拡張要求がキューで待機され、アップグレード完了後に順次処理されます。アップグレード開始前に、コンソールの詳細ページで予想所要時間とノード別の進捗状況を確認できます。必要に応じて、ノードプール単位でアップグレードを一時停止またはロールバックできます。ロールバックは最後に成功したマイナーバージョンのみが対象です。ロールバック後も、コントロールプレーンは最新マイナーバージョンを維持します。ロールバック後に再度アップグレードを試行する場合は、失敗原因を解決してから、コンソールで再試行ボタンをクリックしてください。(本文修正テスト：この文は翻訳の再実行時に反映される必要があります。)

<a id="upgrade-policy"></a>
### アップグレードポリシー { #upgrade-policy }

各マイナーバージョンの標準サポート期間はリリースから 12 か月です。サポート終了の 60 日前からコンソールバナーと通知チャネルを通じて事前案内が配信され、サポート終了日を過ぎたクラスターは自動的に最新のマイナーバージョンに昇格されます。自動昇格が予定されているクラスターは、サポート終了の 30 日前からコンソール詳細ページの上部にカウントダウンバナーが表示され、任意のタイミングで手動でアップグレードを前倒しできます。
