## Compute > Instance > バージョンガイド { #compute-instance-version-guide }

インスタンスサービスが対応するクラスターイメージバージョンとリリース履歴を整理したドキュメントです。各バージョンで導入された主要な変更内容とマイナーバージョンアップグレードポリシー、サポート終了スケジュールについて紹介します。新規クラスターを作成する場合、最新のマイナーバージョンがデフォルトで選択されます。既に運用中のクラスターは、コンソールまたは API を通じてマイナーバージョンアップグレードを申請できます。マイナーバージョンアップグレードはノードプール単位で無停止ローリング方式で実施され、データプレーンには影響がありません。ただし、コントロールプレーンで短い遅延が発生する可能性があるため、トラフィックが低い時間帯に予約実行することをお勧めします。アップグレード進行中は、新規ワークロード配置とノードプール拡張リクエストがキューで待機され、アップグレード完了後に順次処理されます。アップグレード開始前に、コンソールの詳細ページで予想所要時間とノード別進行状況を確認できます。必要に応じて、ノードプール単位でアップグレードを一時停止またはロールバックできます。ロールバックは最後に成功したマイナーバージョンのみが可能であり、ロールバック後もコントロールプレーンは最新のマイナーバージョンを維持します。ロールバック後に再度アップグレードを試みる場合は、障害原因を解決した後、コンソールの再試行ボタンをクリックしてください。（本文修正テスト：この文は翻訳再実行時に反映されるべきです。）

<a id="upgrade-policy"></a>
### アップグレードポリシー { #upgrade-policy }

各マイナーバージョンの標準サポート期間はリリースから 12 か月です。サポート終了の 60 日前からコンソールバナーと通知チャネルを通じて事前案内が配信され、サポート終了日を過ぎたクラスターは自動的に最新のマイナーバージョンに昇格されます。自動昇格が予定されているクラスターは、サポート終了の 30 日前からコンソール詳細ページの上部にカウントダウンバナーが表示され、任意のタイミングで手動でアップグレードを前倒しできます。
