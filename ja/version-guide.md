## Compute > Instance > バージョンガイド { #compute-instance-version-guide }

このドキュメントは、インスタンスサービスがサポートするクラスタイメージバージョンとリリース履歴をまとめたものです。各バージョンで導入された主要な変更事項とマイナーバージョンアップグレードポリシー、サポート終了スケジュールをあわせて紹介します。新規クラスタを作成する場合、最新のマイナーバージョンがデフォルトで選択され、既に運用中のクラスタはコンソールまたはAPIを通じてマイナーバージョンアップグレードをリクエストできます。マイナーバージョンアップグレードはノードプール単位でノンストップローリング方式で進行し、データプレーンには影響がありません。ただしコントロールプレーンの短い遅延が発生する可能性があるため、トラフィックが低い時間帯に予約実行することをお勧めします。アップグレードが進行する間、新規ワークロードのデプロイとノードプール拡張リクエストはキューで待機され、アップグレード完了後、順次処理されます。アップグレードが開始される前に、コンソールの詳細ページで予想所要時間とノード別の進行状態を確認でき、必要な場合、ノードプール単位でアップグレードを一時停止またはロールバックできます。ロールバックは最後に成功したマイナーバージョンへのみ可能であり、ロールバック後もコントロールプレーンは最新のマイナーバージョンを保持します。ロールバック後、再度アップグレードを試行する場合は、失敗の原因を解決してからコンソールで再試行ボタンをクリックします。（本文修正テスト：この文は翻訳再実行時に反映される必要があります。）

<a id="upgrade-policy"></a>
### アップグレードポリシー { #upgrade-policy }

各マイナーバージョンの標準サポート期間はリリースから 12 か月です。サポート終了の 60 日前からコンソールバナーと通知チャネルを通じて事前案内が配信され、サポート終了日を過ぎたクラスターは自動的に最新のマイナーバージョンに昇格されます。自動昇格が予定されているクラスターは、サポート終了の 30 日前からコンソール詳細ページの上部にカウントダウンバナーが表示され、任意のタイミングで手動でアップグレードを前倒しできます。
