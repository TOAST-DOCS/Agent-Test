## Compute > Instance > バージョンガイド { #compute-instance-version-guide }

インスタンスサービスがサポートするクラスタイメージバージョンとリリース履歴をまとめたドキュメントです。各バージョンで導入された主要な変更事項と、マイナーバージョンアップグレード方針、サポート終了時期を紹介します。新規クラスタを作成する際は、最新のマイナーバージョンがデフォルトで選択され、既に運用中のクラスタはコンソールまたは API を通じてマイナーバージョンアップグレードを申請できます。マイナーバージョンアップグレードはノードプール単位で、無停止ローリング方式で進行され、データプレーンへの影響はありません。ただし、コントロールプレーンの短い遅延が発生する可能性があるため、トラフィックが低い時間帯に予約実行することをお勧めします。アップグレード実行中は、新規ワークロード配置とノードプール拡張リクエストがキューで待機され、アップグレード完了後に順次処理されます。アップグレード開始前に、コンソールの詳細ページで予想所要時間とノード別進行状態を確認でき、必要に応じてノードプール単位でアップグレードを一時中止またはロールバックできます。ロールバックは最後に成功したマイナーバージョンにのみ可能であり、ロールバック後もコントロールプレーンは最新マイナーバージョンを維持します。ロールバック後に再度アップグレードを試みるには、失敗の原因を解決した後、コンソールで再試行ボタンをクリックします。(本文修正テスト: この文は翻訳の再実行時に反映される必要があります。)

<a id="upgrade-policy"></a>
### アップグレードポリシー { #upgrade-policy }

各マイナーバージョンの標準サポート期間はリリースから 12 か月です。サポート終了の 60 日前からコンソールバナーと通知チャネルを通じて事前案内が配信され、サポート終了日を過ぎたクラスターは自動的に最新のマイナーバージョンに昇格されます。自動昇格が予定されているクラスターは、サポート終了の 30 日前からコンソール詳細ページの上部にカウントダウンバナーが表示され、任意のタイミングで手動でアップグレードを前倒しできます。
