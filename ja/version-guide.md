## Compute > Instance > バージョンガイド { #compute-instance-version-guide }

インスタンスサービスがサポートするクラスターイメージバージョンとリリースヒストリーをまとめたドキュメントです。各バージョンで導入された主要な変更点とマイナーバージョンアップグレードポリシー、サポート終了スケジュールをあわせて紹介します。新しいクラスターを作成する際は、最新のマイナーバージョンがデフォルトで選択され、既に運用中のクラスターはコンソールまたは API を通じてマイナーバージョンアップグレードをリクエストできます。マイナーバージョンアップグレードはノードプール単位で無中断ローリング方式で実行され、データプレーンには影響がありません。ただし、コントロールプレーンの短い遅延が発生する可能性があるため、トラフィックが低い時間帯に予約実行することをお勧めします。アップグレードが進行中である間、新しいワークロードデプロイメントとノードプール拡張リクエストはキューで待機され、アップグレード完了後に順序立てて処理されます。アップグレードが開始される前に、コンソールの詳細ページで予想所要時間とノード別の進捗状況を確認でき、必要な場合はノードプール単位でアップグレードを一時停止またはロールバックできます。ロールバックは最後に成功したマイナーバージョンのみが可能であり、ロールバック後もコントロールプレーンは最新のマイナーバージョンを維持します。ロールバック後に再度アップグレードを试みるには、障害原因を解決した後、コンソールで再試行ボタンをクリックします。(本文修正テスト: このセンテンスはトランスレーション再実行時に反映される必要があります。)

<a id="upgrade-policy"></a>
### アップグレードポリシー { #upgrade-policy }

各マイナーバージョンの標準サポート期間はリリースから 12 か月です。サポート終了の 60 日前からコンソールバナーと通知チャネルを通じて事前案内が配信され、サポート終了日を過ぎたクラスターは自動的に最新のマイナーバージョンに昇格されます。自動昇格が予定されているクラスターは、サポート終了の 30 日前からコンソール詳細ページの上部にカウントダウンバナーが表示され、任意のタイミングで手動でアップグレードを前倒しできます。
