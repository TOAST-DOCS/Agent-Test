## Compute > Instance > バージョンガイド { #compute-instance-version-guide }

インスタンス サービスでサポートされるクラスタ イメージ バージョンおよびリリース履歴をまとめたドキュメントです。各バージョンで導入された主な変更事項、マイナー バージョン アップグレード ポリシー、およびサポート終了予定について説明します。新しいクラスタを作成する際は、最新のマイナー バージョンがデフォルトとして選択され、既に運用中のクラスタはコンソールまたは API を介してマイナー バージョン アップグレードをリクエストできます。マイナー バージョン アップグレードはノード プール 単位でノンストップ ローリング方式で進行し、データプレーンに影響がありません。ただし、コントロール プレーンで短い遅延が発生する可能性があるため、トラフィックが低い時間帯に予約実行することをお勧めします。アップグレード進行中は、新しいワークロード デプロイおよびノード プール拡張リクエストがキューで待機され、アップグレード完了後に順次処理されます。アップグレード開始前にコンソールの詳細ページで予想所要時間およびノード別の進行状態を確認でき、必要に応じてノード プール 単位でアップグレードを一時停止またはロールバックできます。ロールバックは最後に成功したマイナー バージョンのみで可能であり、ロールバック後もコントロール プレーンは最新のマイナー バージョンを維持します。ロールバック後に再度アップグレードを試みるには、失敗の原因を解決した後、コンソールで再試行ボタンをクリックしてください。（本文修正テスト：この文は翻訳を再実行する際に反映される必要があります。）

<a id="upgrade-policy"></a>
### アップグレードポリシー { #upgrade-policy }

各マイナーバージョンの標準サポート期間はリリースから 12 か月です。サポート終了の 60 日前からコンソールバナーと通知チャネルを通じて事前案内が配信され、サポート終了日を過ぎたクラスターは自動的に最新のマイナーバージョンに昇格されます。自動昇格が予定されているクラスターは、サポート終了の 30 日前からコンソール詳細ページの上部にカウントダウンバナーが表示され、任意のタイミングで手動でアップグレードを前倒しできます。
