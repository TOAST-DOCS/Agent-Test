## Compute > Instance > バージョンガイド { #compute-instance-version-guide }

インスタンスサービスがサポートするクラスタイメージバージョンとリリース履歴をまとめたドキュメントです。各バージョンで導入された主要な変更事項とマイナー バージョン アップグレード ポリシー、およびサポート終了スケジュールをあわせて紹介します。新規クラスタを作成する場合、最新のマイナー バージョンがデフォルトで選択されます。すでに運用中のクラスタは、コンソールまたは API を通じてマイナー バージョン アップグレードをリクエストできます。マイナー バージョン アップグレードはノードプール単位で無中断ローリング方式で進行し、データプレーンには影響がありません。ただし、コントロールプレーンで短い遅延が発生する可能性があるため、トラフィックが低い時間帯に予約実行することをお勧めします。アップグレードが進行している間、新しいワークロード配置とノードプール拡張リクエストはキューで待機され、アップグレード完了後に順番に処理されます。アップグレードが開始される前に、コンソールの詳細ページで想定所要時間とノード別の進捗状況を確認できます。必要な場合は、ノードプール単位でアップグレードを一時停止またはロールバックできます。ロールバックは最後に成功したマイナー バージョンへの復帰のみ可能です。ロールバック後も、コントロールプレーンは最新のマイナー バージョンを保持します。ロールバック後に再度アップグレードを試みるには、失敗原因を解消してからコンソールで再試行ボタンをクリックします。(本文修正テスト：この文は翻訳の再実行時に反映される必要があります。)

<a id="upgrade-policy"></a>
### アップグレードポリシー { #upgrade-policy }

各マイナーバージョンの標準サポート期間はリリースから 12 か月です。サポート終了の 60 日前からコンソールバナーと通知チャネルを通じて事前案内が配信され、サポート終了日を過ぎたクラスターは自動的に最新のマイナーバージョンに昇格されます。自動昇格が予定されているクラスターは、サポート終了の 30 日前からコンソール詳細ページの上部にカウントダウンバナーが表示され、任意のタイミングで手動でアップグレードを前倒しできます。
