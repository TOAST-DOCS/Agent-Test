## Compute > Instance > バージョンガイド { #compute-instance-version-guide }

インスタンスサービスがサポートするクラスタイメージバージョンとリリース履歴をまとめたドキュメントです。各バージョンで導入された主要な変更事項とマイナーバージョンアップグレードポリシー、サポート終了スケジュールを紹介します。新規クラスタを作成する場合、最新マイナーバージョンがデフォルトで選択されます。既に運用中のクラスタは、コンソールまたは API を通じてマイナーバージョンアップグレードをリクエストできます。マイナーバージョンアップグレードはノードプール単位でノンストップローリング方式で実行され、データプレーンは影響を受けません。ただし、コントロールプレーンで短い遅延が発生する可能性があるため、トラフィックが低い時間帯に予約実行することをお勧めします。アップグレード進行中は、新規ワークロードデプロイとノードプール拡張リクエストがキューで待機され、アップグレード完了後に順次処理されます。アップグレード開始前にコンソールの詳細ページで予想所要時間とノード単位の進行状況を確認できます。必要な場合、ノードプール単位でアップグレードを一時停止またはロールバックできます。ロールバックは最後に成功したマイナーバージョンへの戻し処理のみ可能です。ロールバック後もコントロールプレーンは最新マイナーバージョンを維持します。ロールバック後に再度アップグレードを実行する場合は、エラー原因を解決した後、コンソールの再試行ボタンをクリックします。(本文修正テスト: このセンテンスはアップデート実行時に反映される必要があります。)

<a id="upgrade-policy"></a>
### アップグレードポリシー { #upgrade-policy }

各マイナーバージョンの標準サポート期間はリリースから 12 か月です。サポート終了の 60 日前からコンソールバナーと通知チャネルを通じて事前案内が配信され、サポート終了日を過ぎたクラスターは自動的に最新のマイナーバージョンに昇格されます。自動昇格が予定されているクラスターは、サポート終了の 30 日前からコンソール詳細ページの上部にカウントダウンバナーが表示され、任意のタイミングで手動でアップグレードを前倒しできます。
