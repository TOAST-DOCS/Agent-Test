## Compute > Instance > バージョンガイド { #compute-instance-version-guide }

インスタンスサービスが対応するクラスターイメージのバージョンとリリース履歴をまとめたドキュメントです。各バージョンで導入された主要な変更点とマイナーバージョンアップグレードポリシー、サポート終了スケジュールについて説明します。新規クラスターを作成する場合は、最新のマイナーバージョンがデフォルトで選択されます。既に運用中のクラスターは、コンソールまたは API を通じてマイナーバージョンアップグレードをリクエストできます。マイナーバージョンアップグレードはノードプール単位で無停止ローリング方式で実行され、データプレーンに影響はありません。ただし、コントロールプレーンに短い遅延が生じる可能性があるため、トラフィックが低い時間帯に予約実行することをお勧めします。アップグレード中は、新規ワークロードのデプロイとノードプール拡張リクエストがキューで待機し、アップグレード完了後に順序立てて処理されます。アップグレード開始前は、コンソールの詳細ページで予想所要時間とノード別の進行状況を確認できます。必要に応じて、ノードプール単位でアップグレードを一時停止またはロールバックできます。ロールバックは最後に成功したマイナーバージョンにのみ可能で、ロールバック後もコントロールプレーンは最新のマイナーバージョンを保持します。ロールバック後に再度アップグレードを試行する場合は、障害の原因を解決したうえで、コンソールの再試行ボタンをクリックしてください。(本文修正テスト: このセンテンスはアップグレード再実行時に反映される必要があります。)

<a id="upgrade-policy"></a>
### アップグレードポリシー { #upgrade-policy }

各マイナーバージョンの標準サポート期間はリリースから 12 か月です。サポート終了の 60 日前からコンソールバナーと通知チャネルを通じて事前案内が配信され、サポート終了日を過ぎたクラスターは自動的に最新のマイナーバージョンに昇格されます。自動昇格が予定されているクラスターは、サポート終了の 30 日前からコンソール詳細ページの上部にカウントダウンバナーが表示され、任意のタイミングで手動でアップグレードを前倒しできます。
