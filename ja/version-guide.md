## Compute > Instance > バージョンガイド { #compute-instance-version-guide }

インスタンスサービスがサポートするクラスタイメージバージョンとリリース履歴を整理したドキュメントです。各バージョンで導入された主な変更内容とマイナーバージョンアップグレードポリシー、サポート終了スケジュールを一緒に紹介します。新しいクラスタを作成する場合、最新のマイナーバージョンがデフォルトで選択されます。すでに運営中のクラスタはコンソールまたは API を通じてマイナーバージョンアップグレードを申請できます。マイナーバージョンアップグレードはノードプール単位で無中断ローリング方式で進行され、データプレーンには影響がありません。ただし、コントロールプレーンで短い遅延が発生する可能性があるため、トラフィックが低い時間帯に予約実行することをお勧めします。アップグレードが進行中に、新しいワークロードの展開とノードプール拡張リクエストはキューで待機され、アップグレード完了後に順次処理されます。アップグレードが開始される前に、コンソールの詳細ページで予想所要時間とノード別進行状態を確認できます。必要な場合、ノードプール単位でアップグレードを一時停止したり、ロールバックしたりできます。ロールバックは最後に成功したマイナーバージョンでのみ可能であり、ロールバック後もコントロールプレーンは最新のマイナーバージョンを保持します。ロールバック後に再度アップグレードを試みるには、失敗の原因を解決した後、コンソールで再試行ボタンをクリックしてください。(本文修正テスト: この文は翻訳の再実行時に反映される必要があります。)

<a id="upgrade-policy"></a>
### アップグレードポリシー { #upgrade-policy }

各マイナーバージョンの標準サポート期間はリリースから 12 か月です。サポート終了の 60 日前からコンソールバナーと通知チャネルを通じて事前案内が配信され、サポート終了日を過ぎたクラスターは自動的に最新のマイナーバージョンに昇格されます。自動昇格が予定されているクラスターは、サポート終了の 30 日前からコンソール詳細ページの上部にカウントダウンバナーが表示され、任意のタイミングで手動でアップグレードを前倒しできます。
