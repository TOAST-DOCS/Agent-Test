## Compute > Instance > バージョンガイド { #compute-instance-version-guide }

インスタンス サービスが対応するクラスター イメージ バージョンおよびリリース ヒストリーをまとめた文書です。各バージョンで導入された主な変更内容、マイナー バージョン アップグレード ポリシー、サポート終了予定を紹介します。新しいクラスターを作成する際は、最新のマイナー バージョンがデフォルトとして選択されます。運用中のクラスターの場合、コンソールまたは API を通じてマイナー バージョン アップグレードをリクエストできます。マイナー バージョン アップグレードはノード プール単位でノンストップ ローリング方式で実行され、データ プレーンには影響がありません。ただし、コントロール プレーンで短い遅延が発生する可能性があるため、トラフィックが低い時間帯に予約実行することをお勧めします。アップグレード中は、新しいワークロード デプロイメントおよびノード プール スケーリング リクエストがキューで待機され、アップグレード完了後に順序どおり処理されます。アップグレード開始前に、コンソールの詳細ページで予想所要時間およびノード別の進行状況を確認できます。必要に応じて、ノード プール単位でアップグレードを一時停止またはロールバックできます。ロールバックは、最後に成功したマイナー バージョンへの実行のみが可能です。ロールバック後もコントロール プレーンは最新のマイナー バージョンを維持します。ロールバック後に再度アップグレードを試行するには、失敗の原因を解決した後、コンソールで再試行ボタンをクリックします。(本文修正テスト: この文は翻訳再実行時に反映される必要があります。)

<a id="upgrade-policy"></a>
### アップグレードポリシー { #upgrade-policy }

各マイナーバージョンの標準サポート期間はリリースから 12 か月です。サポート終了の 60 日前からコンソールバナーと通知チャネルを通じて事前案内が配信され、サポート終了日を過ぎたクラスターは自動的に最新のマイナーバージョンに昇格されます。自動昇格が予定されているクラスターは、サポート終了の 30 日前からコンソール詳細ページの上部にカウントダウンバナーが表示され、任意のタイミングで手動でアップグレードを前倒しできます。
