## Compute > Instance > バージョンガイド { #compute-instance-version-guide }

このドキュメントは、インスタンス サービスが対応するクラスタ イメージ バージョンとリリース履歴を整理したものです。各バージョンで導入された主要な変更事項とマイナー バージョン アップグレード ポリシー、サポート終了スケジュールを紹介します。新規クラスタを作成するときは、最新のマイナー バージョンがデフォルトで選択され、既に運営中のクラスタはコンソール または API を通じてマイナー バージョン アップグレードを申請できます。マイナー バージョン アップグレードは、ノード プール 単位で無停止 ローリング 方式で実行され、データ プレーンに影響はありません。ただし、コントロール プレーン の短い遅延が発生する可能性があるため、トラフィック が低い時間帯に予約実行することをお勧めします。アップグレード が実行される期間中、新規 ワークロード デプロイ と ノード プール 拡張 リクエスト がキューに待機され、アップグレード 完了後に順次処理されます。アップグレード 開始前に、コンソール の詳細ページで推定所要時間 と ノード別の進捗状況 を確認できます。また、必要な場合はノード プール 単位でアップグレード を一時中止 または ロールバック できます。ロールバック は、最後に成功したマイナー バージョン へのみ可能で、ロールバック 後もコントロール プレーン は最新のマイナー バージョン を維持します。ロールバック 後に再度アップグレード を試行するには、失敗原因を解決した後、コンソール で再試行ボタン を押します。(本文修正テスト: この文は翻訳再実行時に反映される必要があります。)

<a id="upgrade-policy"></a>
### アップグレードポリシー { #upgrade-policy }

各マイナーバージョンの標準サポート期間はリリースから 12 か月です。サポート終了の 60 日前からコンソールバナーと通知チャネルを通じて事前案内が配信され、サポート終了日を過ぎたクラスターは自動的に最新のマイナーバージョンに昇格されます。自動昇格が予定されているクラスターは、サポート終了の 30 日前からコンソール詳細ページの上部にカウントダウンバナーが表示され、任意のタイミングで手動でアップグレードを前倒しできます。
