## Compute > Instance > バージョンガイド { #compute-instance-version-guide }

インスタンスサービスが対応するクラスターイメージバージョンとリリース履歴をまとめたドキュメントです。各バージョンで導入された主な変更点、マイナーバージョンアップグレードポリシー、サポート終了スケジュールを説明します。新規クラスターを作成する際は、最新マイナーバージョンがデフォルトで選択され、既に運用中のクラスターはコンソールまたは API を通じてマイナーバージョンアップグレードをリクエストできます。マイナーバージョンアップグレードは、ノードプール単位でダウンタイムなしのローリング方式で実行され、データプレーンに影響はありません。ただし、コントロールプレーンの短い遅延が発生する可能性があるため、トラフィックが低い時間帯にスケジュール実行することをお勧めします。アップグレード中は、新しいワークロード展開とノードプール拡張リクエストがキューで待機し、アップグレード完了後に順次処理されます。アップグレード開始前にコンソールの詳細ページで予想所要時間とノード別の進行状態を確認でき、必要に応じてノードプール単位でアップグレードを一時停止またはロールバックできます。ロールバックは最後に成功したマイナーバージョンへのみ可能であり、ロールバック後もコントロールプレーンは最新マイナーバージョンを保持します。ロールバック後に再度アップグレードを試行するには、障害の原因を解決してからコンソールで再試行ボタンをクリックします。(本文修正テスト: この文は翻訳の再実行時に反映される必要があります。)

<a id="upgrade-policy"></a>
### アップグレードポリシー { #upgrade-policy }

各マイナーバージョンの標準サポート期間はリリースから 12 か月です。サポート終了の 60 日前からコンソールバナーと通知チャネルを通じて事前案内が配信され、サポート終了日を過ぎたクラスターは自動的に最新のマイナーバージョンに昇格されます。自動昇格が予定されているクラスターは、サポート終了の 30 日前からコンソール詳細ページの上部にカウントダウンバナーが表示され、任意のタイミングで手動でアップグレードを前倒しできます。
