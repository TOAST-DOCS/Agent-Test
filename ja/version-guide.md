## Compute > Instance > バージョンガイド { #compute-instance-version-guide }

インスタンスサービスがサポートするクラスターイメージのバージョンとリリース履歴をまとめたドキュメントです。各バージョンで導入された主な変更点、マイナーバージョンアップグレードポリシー、サポート終了スケジュールを紹介します。新しいクラスターを作成する際は最新のマイナーバージョンが既定で選択され、すでに運用中のクラスターはコンソールまたは API を通じてマイナーバージョンアップグレードを申請できます。マイナーバージョンアップグレードはノードプール単位で無停止のローリング方式で進み、データプレーンには影響しません。ただし、コントロールプレーンで短い遅延が発生する場合があるため、トラフィックの少ない時間帯に予約実行することを推奨します。アップグレードが進行している間は、新しいワークロードのデプロイやノードプールの拡張リクエストはキューに蓄積され、アップグレード完了後に順次処理されます。アップグレードが開始される前に、コンソールの詳細ページで所要時間の見積もりとノードごとの進行状況を確認でき、必要に応じてノードプール単位でアップグレードを一時停止したりロールバックしたりできます。ロールバックは直前に成功したマイナーバージョンにのみ可能で、ロールバック後もコントロールプレーンは最新のマイナーバージョンを維持します。ロールバック後に再度アップグレードを試みるには、失敗原因を解消したうえでコンソールの再試行ボタンを押してください。

<a id="upgrade-policy"></a>
### アップグレードポリシー { #upgrade-policy }

各マイナーバージョンの標準サポート期間はリリースから 12 か月です。サポート終了の 60 日前からコンソールバナーと通知チャネルを通じて事前案内が配信され、サポート終了日を過ぎたクラスターは自動的に最新のマイナーバージョンに昇格されます。自動昇格が予定されているクラスターは、サポート終了の 30 日前からコンソール詳細ページの上部にカウントダウンバナーが表示され、任意のタイミングで手動でアップグレードを前倒しできます。
