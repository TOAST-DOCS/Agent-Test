## Compute > Instance > バージョンガイド { #compute-instance-version-guide }

インスタンスサービスがサポートするクラスターイメージバージョンとリリース履歴を整理したドキュメントです。各バージョンで導入された主要な変更事項とマイナーバージョンアップグレードポリシー、サポート終了スケジュールを併せて紹介します。新規クラスターを作成する場合、最新のマイナーバージョンがデフォルトで選択され、既に運用中のクラスターはコンソールまたは API を使用してマイナーバージョンアップグレードをリクエストできます。マイナーバージョンアップグレードはノードプール単位で無停止ローリング方式で実行され、データプレーンには影響がありません。ただし、コントロールプレーンの短い遅延が発生する可能性があるため、トラフィックが低い時間帯に予約実行することをお勧めします。アップグレードが進行している間は、新規ワークロードデプロイとノードプール拡張リクエストがキューで待機され、アップグレード完了後に順次処理されます。アップグレード開始前にコンソールの詳細ページで予想所要時間とノード別の進行状況を確認できます。必要に応じて、ノードプール単位でアップグレードを一時停止またはロールバックできます。ロールバックは最後に成功したマイナーバージョンのみ可能であり、ロールバック後もコントロールプレーンは最新のマイナーバージョンを維持します。ロールバック後に再度アップグレードを試みる場合は、失敗原因を解決してからコンソールで再試行ボタンをクリックしてください。(本文修正テスト: この文は翻訳再実行時に反映される必要があります。)

<a id="upgrade-policy"></a>
### アップグレードポリシー { #upgrade-policy }

各マイナーバージョンの標準サポート期間はリリースから 12 か月です。サポート終了の 60 日前からコンソールバナーと通知チャネルを通じて事前案内が配信され、サポート終了日を過ぎたクラスターは自動的に最新のマイナーバージョンに昇格されます。自動昇格が予定されているクラスターは、サポート終了の 30 日前からコンソール詳細ページの上部にカウントダウンバナーが表示され、任意のタイミングで手動でアップグレードを前倒しできます。
