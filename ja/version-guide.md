## Compute > Instance > バージョンガイド { #compute-instance-version-guide }

インスタンス サービスがサポートするクラスタイメージバージョンとリリース履歴をまとめたドキュメントです。各バージョンで導入された主要な変更事項とマイナーバージョンアップグレードポリシー、サポート終了スケジュールをあわせて紹介します。新しいクラスタを作成するときは、最新のマイナーバージョンがデフォルトとして選択され、すでに運営中のクラスタはコンソールまたは API を通じてマイナーバージョンアップグレードをリクエストできます。マイナーバージョンアップグレードはノードプール単位で無停止ローリング方式で進行され、データプレーンには影響がありません。ただし、コントロールプレーンの短い遅延が発生する可能性があるため、トラフィックが低い時間帯に予約実行することをお勧めします。アップグレードが進行されている間、新しいワークロード展開とノードプール拡張リクエストはキューに待機され、アップグレード完了後に順次処理されます。アップグレードが開始される前に、コンソールの詳細ページで予想所要時間とノード別の進行状態を確認でき、必要に応じてノードプール単位でアップグレードを一時停止またはロールバックできます。ロールバックは最後に成功したマイナーバージョンのみ可能であり、ロールバック以降もコントロールプレーンは最新マイナーバージョンを保持します。ロールバック以降、再度アップグレードを試みるには、失敗原因を解決した後、コンソールで再試行ボタンをクリックすればよいです。(本文修正テスト：この文章は翻訳再実行時に反映される必要があります。)

<a id="upgrade-policy"></a>
### アップグレードポリシー { #upgrade-policy }

各マイナーバージョンの標準サポート期間はリリースから 12 か月です。サポート終了の 60 日前からコンソールバナーと通知チャネルを通じて事前案内が配信され、サポート終了日を過ぎたクラスターは自動的に最新のマイナーバージョンに昇格されます。自動昇格が予定されているクラスターは、サポート終了の 30 日前からコンソール詳細ページの上部にカウントダウンバナーが表示され、任意のタイミングで手動でアップグレードを前倒しできます。
