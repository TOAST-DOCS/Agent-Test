## 単変量時系列異常検出概要 { #term-pin-overview }

このドキュメントは単変量時系列異常検出機能について説明します。

### 1. 単変量時系列異常検出設定1 { #term-pin-1 }

単変量時系列異常検出アプリを作成するには、まずデータソースを準備します。単変量時系列異常検出は、指標の過去のパターンを学習して異常セクションを見つけます。

1. コンソールで**[単変量時系列異常検出]**タブに移動します。このタブで単変量時系列異常検出アプリのリストを確認できます。
2. 学習期間と推論期間を指定します。期間が短いほど単変量時系列異常検出の反応が速くなりますが、コストが増加します。
3. しきい値を設定します。単変量時系列異常検出は、スコアがしきい値を超えると異常と判定します。
4. **[作成]**ボタンをクリックします。単変量時系列異常検出アプリが作成され、学習が開始されます。

> 注記: 単変量時系列異常検出アプリは、プロジェクトごとに最大10個まで作成できます。詳細については、「単変量時系列異常検出使用ガイド」を参照してください。
