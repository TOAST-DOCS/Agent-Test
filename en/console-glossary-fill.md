# Fill Sample

<a id="cgf-intro"></a>
## Introduction

This document describes the **Allowed lateness** and **Reason for failure included** options.

<a id="cgf-fields"></a>
## Window Fields

| Item | Default |
| --- | --- |
| Allowed Delay Time | 0 |

If you set the allowed delay time to 0, late-arriving messages will be discarded. To receive failure reasons by email, enable the option to include failure reasons.
