# Fill Sample

<a id="cgf-intro"></a>
## Introduction

This document describes the **Allowed lateness** and **Reason for failure included** options.

<a id="cgf-fields"></a>
## Window Fields

| Item | Default value |
| --- | --- |
| Allowed lateness | 0 |

If you set **Allowed lateness** to 0, late-arriving messages are discarded. To receive failure reasons by email, turn on the **Reason for failure included** option.
