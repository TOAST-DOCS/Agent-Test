# Fill Sample

<a id="cgf-intro"></a>
## Introduction

This document describes the **Allowed lateness** and **Reason for failure included** options.

<a id="cgf-fields"></a>
## Window Fields

| Item | Default |
| --- | --- |
| Allowed lateness | 0 |

If Allowed lateness is set to 0, messages that arrive late are discarded. To receive failure reasons by email, enable the Reason for failure included option.
