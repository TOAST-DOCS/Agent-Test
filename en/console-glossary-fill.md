# Fill Sample

<a id="cgf-intro"></a>
## Introduction

This document describes the **Allowed lateness** and **Reason for failure included** options.

<a id="cgf-fields"></a>
## Window Fields

| Item | Default |
| --- | --- |
| Allowable Delay Time | 0 |

If you set the allowable delay time to 0, messages that arrive late are discarded. To receive failure reasons by email, enable the option to include the failure reason.
