## Sample > Template tag format collection { #sample-template-tags }

This document is a fixture for verifying that mkdocs-macros template tags continue to build after translation and that **Korean strings** inserted by the author inside the tags are translated. The tags in the `$[ product_name ]$` document are taken directly from actual user guides (Private-DNS, Storage-Object-Storage, Storage-Online-NAS, nhn-cloud-foundry).

<a id="tt-set-literal"></a>
### Korean strings in variables { #tt-set-literal }

The `set` block at the top of the document stores different values in variables depending on the build environment. The region covered by this guide is $[ region_names ]$, and the API host is `$[ api_host ]$`.

| Category | Value | Note |
|---|---|---|
| Region | $[ region_names ]$ | Varies by environment |
| API host | `$[ api_host ]$` | A variable name containing an underscore |
| Query start time | {{executionTime}} | A placeholder substituted by the workflow engine |
