## Compute > Instance > Pricing guide { #compute-instance-pricing-guide }

Instance pricing plans and usage limits by plan. Pricing may vary depending on the region and billing method. You can check the exact pricing in the cost calculator in the console. (Text modification test: This sentence should be reflected when the translation is re-run.)

<a id="plan-limits"></a>
### Limits by plan { #plan-limits }

| Plan | Max instances | Max block storage | Technical support |
|---|---|---|---|
| Basic plan | 10 | 1TB | Email support |
| Standard plan | 50 | 10TB | Email and phone support |
| Premium plan | 200 | 50TB | Dedicated engineer support |

<a id="billing-notes"></a>
### Billing notes { #billing-notes }

Billing is calculated hourly, and storage charges continue to accrue even when an instance is stopped. If you use a monthly-cap plan, any usage above the cap is not billed.

<a id="snapshot-defaults"></a>
### Snapshot defaults { #snapshot-defaults }

| Item | Description |
|---|---|
| Backup cycle | A snapshot is taken automatically once per day. |
| Retention period | Snapshots that have been created are kept for 30 days. |
| Restore method | You can restore directly from the console. |
