## Univariate Time Series Anomaly Detection Overview { #term-pin-overview }

This document describes the univariate time series anomaly detection feature.

### 1. Univariate Time Series Anomaly Detection Configuration 1 { #term-pin-1 }

To create a univariate time series anomaly detection app, first prepare a data source. The univariate time series anomaly detection learns past patterns in metrics to find anomalous sections.

1. In the console, navigate to the **Univariate Time Series Anomaly Detection** tab. You can view the list of univariate time series anomaly detection apps from this tab.
2. Specify the training period and inference period. The shorter the period, the faster the univariate time series anomaly detection responds, but costs increase.
3. Set the threshold. The univariate time series anomaly detection determines it as anomalous when the score exceeds the threshold.
4. Click the Create button. The univariate time series anomaly detection app is created and training begins.

> Note: You can create up to 10 univariate time series anomaly detection apps per project. For more information, see the univariate time series anomaly detection user guide.
