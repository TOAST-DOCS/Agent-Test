## Univariate Time Series Anomaly Detection Overview { #term-pin-overview }

This document describes the univariate time series anomaly detection feature.

### 1. Univariate Time Series Anomaly Detection Configuration 1 { #term-pin-1 }

To create a univariate time series anomaly detection application, you must first prepare a data source. Univariate time series anomaly detection learns the past patterns of metrics to identify abnormal intervals.

1. In the console, navigate to the **Univariate Time Series Anomaly Detection** tab. In this tab, you can view the list of univariate time series anomaly detection applications.
2. Specify the learning period and inference period. The shorter the period, the faster the univariate time series anomaly detection responds, but costs increase.
3. Set the threshold value. Univariate time series anomaly detection determines an anomaly when the score exceeds the threshold.
4. Click the Create button. The univariate time series anomaly detection application is created and learning begins.

> Note: You can create up to 10 univariate time series anomaly detection applications per project. For more information, see the Univariate Time Series Anomaly Detection User Guide.
