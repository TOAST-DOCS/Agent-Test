## NotationSample Overview { #notation-sample-overview }

You can use the NotationSample service.
You can check the NotationSample service settings.
You can display the NotationSample service list.

## Limits { #notation-sample-limits }

You can create up to 5 resources per project.
You can query up to 100 items per request.
Data is retained for 30 days.
You can specify up to 10 tags.
You can refresh the NotationSample service status.
You can register up to 5 sender phone numbers per account, and they are approved within 3 days.
